# Sõnad Reader (Lugemik) — Спецификация приложения

## 1. Главная идея

**Sõnad Reader** — приложение-компаньон к словарю `Sõnad`, объединяющее два сценария чтения на эстонском языке:
1. **AI-генератор персонализированных рассказов** на основе реального словарного запаса пользователя из `Sõnad` (`Õpin`, `Raske`, `Sõnavara`, выбранный список/папка).
2. **Умная читалка своих книг (`.epub`, `.fb2`, `.txt`, вставка текста)** в стиле приложения **«Билингва» (KursX) / Readlang**, где:
   - по нажатию на любое слово открывается его начальная форма (лемма), русский перевод и основные формы через движок `Sõnad` (SONAPI);
   - незнакомое слово можно в 1 касание добавить прямо в словарь `Sõnad` (во вкладку `Õpin` или в `Inbox`);
   - по нажатию на значок у абзаца/предложения открывается параллельный перевод всего абзаца на русский язык (плюс краткий грамматический разбор по желанию).

## 2. Основные разделы (Навигация)

1. **Библиотека (`Raamatud`)**:
   - Полка загруженных книг (`.epub`, `.fb2`, `.txt`) и сохранённых AI-рассказов с прогрессом чтения (`%`, текущая глава/абзац).
   - Кнопки: «Загрузить книгу (EPUB / FB2 / TXT)», «Вставить свой текст / статью», «Сгенерировать рассказ со словами из Sõnad».
2. **Генератор рассказов (`Loo lugu` / AI-рассказы)**:
   - Выбор источника слов из синхронизированного словаря `Sõnad`:
     - **«Слова, которые я сейчас учу (`Õpin`)»** (по умолчанию — берёт 8–15 слов);
     - **«Сложные слова (`Raske`)»**;
     - **«Конкретный список / папка из Sõnad»**;
     - Плюс учёт уже известных слов из `Sõnavara`.
   - Выбор уровня сложности текста: `A1`, `A2`, `B1`, `B2`.
   - Выбор жанра / темы: повседневный диалог, детективная история, юмор, путешествие по Эстонии, рабочая ситуация, сказка или своя тема.
   - Результат генерируется со структурой по абзацам: каждый эстонский абзац имеет готовый скрытый русский перевод (открывается по клику на абзац, как в «Билингва»), а целевые слова из `Sõnad` мягко подсвечены в тексте.
3. **Экран чтения (`Lugemine` — режим «Билингва»)**:
   - Чистая, комфортная для глаз типографика (настройка размера шрифта, межстрочного интервала, светлая / сепия / тёмная тема).
   - **Интерактивные слова**: каждое слово в тексте кликабельно.
   - **Индикация слов из вашего словаря `Sõnad`**:
     - Слова со статусом `recalled` / `new` (то есть те, что вы сейчас учите в `Õpin`) имеют деликатное пунктирное подчёркивание;
     - Слова `raske` имеют тёплую янтарную точку/метку;
     - Уже выученные (`sonavara`) не загромождают текст (или подсвечиваются только по желанию).
   - **Нижняя шторка слова (Word Popover) при нажатии на слово**:
     - Показывает словоформу из текста и найденную начальную форму (**лемму**, например `otsuseid → otsus`), уровень CEFR (`A1–C2`), основные формы (`otsus · otsuse · otsust`) и русские переводы из SONAPI.
     - Если слово уже есть в `Sõnad` — показывает плашку **«Уже в Sõnad (Õpin / Sõnavara)»**.
     - Если слова ещё нет — большая удобная кнопка **«+ Добавить в Sõnad»** (сразу сохраняет лемму, формы и выбранный перевод в `Sõnad` через `POST /api/companion/words`) и дополнительная кнопка **«В Inbox»**.
   - **Параллельный перевод абзаца (режим «Билингва»)**:
     - Рядом с каждым абзацем (или по двойному тапу / свайпу по абзацу) раскрывается блок точного русского перевода этого абзаца.
     - Для загруженных книг перевод абзаца запрашивается на лету через подключённый AI-ключ и кэшируется локально в `Dexie`, чтобы повторно не тратить токены.
     - Кнопка **«Разобрать грамматику предложения»** (опционально): AI кратко объясняет падежи и конструкции в этом предложении.
4. **Настройки (`Seaded`)**:
   - **Подключение к Sõnad**:
     - Поле для вставки `API-ключа Sõnad` (`sonad_pat_...`) и URL сервера (по умолчанию `https://sonad.mkin-did-it.workers.dev`).
     - Кнопка «Синхронизировать словарь с Sõnad» + счётчик: сколько слов загружено (`Sõnavara`, `Õpin`, `Raske`).
   - **Подключение нейросети (BYOK)**:
     - Выбор провайдера: `Google Gemini`, `OpenAI (ChatGPT)`, `OpenRouter`, `Anthropic Claude`.
     - Поле для API-ключа + выбор модели (например, `gemini-2.5-flash`, `gpt-4o-mini`) + кнопка «Проверить ключ».

## 3. Этапы реализации (План для первого запуска)

1. **Этап 1 — Каркас PWA и база данных (`Dexie`)**:
   - Инициализировать Vite + React + TypeScript проект в `c:\Users\mrmol\Desktop\SonadReader`.
   - Создать таблицы `Dexie`: `books` (книги и AI-рассказы), `chapters`, `paragraphTranslations` (кэш переводов абзацев), `sonadWords` (локальный кэш словаря из `Sõnad`).
2. **Этап 2 — Клиент интеграции с `Sõnad` и словарём SONAPI**:
   - Подключить `GET /api/companion/words`, `GET /api/companion/lookup`, `POST /api/companion/words` (см. `SONAD_INTEGRATION.md`).
3. **Этап 3 — BYOK AI-модуль и Генератор рассказов**:
   - Реализовать универсальный клиент генерации рассказов и перевода абзацев (Gemini / OpenAI / OpenRouter) со строгим JSON-выводом (`title`, `paragraphs: [{ et, ru }]`, `usedWords`).
4. **Этап 4 — Читалка книг (`.epub`, `.fb2`, `.txt`) в стиле «Билингва»**:
   - Парсер `.epub` / `.fb2` / `.txt`, интерактивная токенизация слов эстонского текста, шторка перевода слова по тапу и параллельный перевод абзацев.
